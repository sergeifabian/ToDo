# ToDo List

Простое приложение для ведения списка дел (ToDo List) с возможностью добавления, редактирования, удаления и поиска задач. Приложение построено на архитектуре VIPER и использует Core Data для локального хранения данных.

## Функциональность

### Список задач
- Отображение всех задач на главном экране.
- Каждая задача содержит название, описание, дату создания и текущий статус (выполнена / не выполнена).
- Поддерживается добавление новых задач.
- Возможность редактирования и удаления существующих задач.
- Реализован поиск по названию и описанию задачи в списке.

### Интеграция с API
При первом запуске приложение автоматически загружает список задач из [DummyJSON API](https://dummyjson.com/todos). Полученные данные сохраняются в Core Data, обеспечивая офлайн-доступ и восстановление при повторных запусках.

### Хранение данных (Core Data)
Все данные о задачах сохраняются в Core Data.  
Приложение поддерживает полный цикл работы с данными:
- Создание, обновление, удаление и поиск задач в локальном хранилище.
- Автоматическое восстановление ранее сохранённых данных при повторном запуске.
- Используется NSPersistentContainer и фоновые контексты для безопасного доступа к данным и многопоточности.

### Многопоточность
Все операции над данными (создание, редактирование, удаление, поиск, загрузка из сети) выполняются в фоновом потоке с использованием GCD. Интерфейс остаётся отзывчивым при любых действиях.

### Архитектура VIPER
Приложение реализовано в соответствии с принципами архитектуры VIPER:
- **View** — отображает интерфейс и реагирует на действия пользователя.  
- **Interactor** — содержит бизнес-логику, включая обращение к Core Data и сетевым уровням.  
- **Presenter** — соединяет View и Interactor, управляет отображением состояния.  
- **Entity** — модель задачи с атрибутами *title*, *description*, *createdAt*, *isCompleted*.  
- **Router** — отвечает за переходы между экранами и навигацию внутри приложения.

### Работа с сетью
При обращении к API используется асинхронный слой загрузки данных, который:
- Получает JSON-список задач с `https://dummyjson.com/todos`.
- Преобразует данные в локальные сущности Core Data.
- Обновляет интерфейс после синхронизации без блокировки основного потока.
